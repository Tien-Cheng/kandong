# Direct ChatGPT plan sign-in

The ChatGPT Backend uses OpenAI's open-source Sign in with ChatGPT flow and calls the public Responses API directly, so learners can connect their ChatGPT plan in a browser without installing the Codex CLI. This adds responsibility for OAuth identity validation, protected credentials and renewal to Kandong, but removes terminal setup; after live sign-in and a completed translation were confirmed, the Codex Backend and its app-server integration were removed, superseding ADR 0001. Connecting a ChatGPT account does not change the Default backend until the user explicitly chooses it, and failures never change Backends or billing paths automatically.

Each registration retains its issued client ID and verified identity independently, including registrations with the same email; secrets live in separate login Keychain records. The direct Responses transport follows the documented preview restrictions, requires a completed stream, and treats sign-in without plan permission as connected identity with AI usage disabled. See [registration and sign-in](https://developers.openai.com/siwc/token-sharing-open-source/sign-in) and [models and inference](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference).

On upgrade, old Codex selections become ChatGPT selections, while explicit ChatGPT preferences and all other Backends are retained. Old Codex model and executable settings are dropped, since they do not configure the direct account's catalog. A user without a saved ChatGPT connection sees the browser sign-in action; Kandong never reads or changes the user's Codex CLI credentials.
